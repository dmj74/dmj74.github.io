## ✅ مرحله ۱ — مخزن گیت‌هاب و آپلود فایل‌ها

۱. در گیت‌هاب یک مخزن بساز: **New repository**
   - نام: `dmj74`
   - **Public** (حتماً Public باشد — نوشتن با توکن انجام می‌شود و هیچ اطلاعات حساسی داخل فایل‌ها نیست)
   - گزینه‌ی «Add a README» را تیک نزن

۲. فایل‌های داخل پوشه‌ی `deploy/` را آپلود کن:
   - در صفحه‌ی مخزن → **Add file → Upload files**
   - همه‌ی این‌ها را بکش و رها کن و **Commit** بزن:

```
index.html        ← سایت
CNAME             ← محتوای آن: dmj74.ir
.nojekyll         ← فایل خالی (مهم: جلوی پردازش Jekyll را می‌گیرد)
sync.json         ← بعداً مقدار owner و repo را درست می‌کنیم
data/site.json    ← داده‌ی اولیه‌ی سایت
```

> 💡 نکته: اگر فایل مخفی `.nojekyll` را نمی‌بینی، در سیستم‌عین ویندوز از `Ctrl+H` یا «View → Hidden items» استفاده کن، یا در گیت‌هاب بعد از آپلود یک فایل جدید با همین نام بساز (خالی).

> 💡 **نام کاربری و نام مخزن تو:** `dmj74` — در همه‌ی فایل‌های این بسته از قبل جای‌گذاری شده است، پس لازم نیست چیزی دستی عوض کنی. (در `sync.json`: `"owner": "dmj74"`, `"repo": "dmj74.github.io"`)
>
> اگر خواستی سایت روی `https://dmj74.github.io` (بدون مسیر اضافه) هم بالا بیاید، مخزن را با نام **`dmj74.github.io`** بساز و در مرحله‌ی ۵ فیلد «نام مخزن» را همان بگذار. با دامنه‌ی اختصاصی `dmj74.ir` هر دو حالت یکسان کار می‌کنند.

## ✅ مرحله ۳ — تنظیم DNS در Cloudflare (مهم‌ترین مرحله)

به **Cloudflare → دامنه dmj74.ir → DNS → Records** برو و **رکوردهای فعلی که به Netlify اشاره می‌کنند را حذف کن**:

> ⚠️ **هشدار:** با این کار سایت فعلی (Netlify) از روی دامنه برداشته می‌شود و سایت جدید (dmj74) جایش می‌آید. اگر می‌خواهی سایت قدیم را نگه داری، به «راه دوم» در انتهای این راهنما نگاه کن.

### رکوردهای جدیدی که باید بسازی

| Type | Name | Content | Proxy | TTL |
|------|------|---------|-------|-----|
| `A` | `@` | `185.199.108.153` | **DNS only** (ابر خاکستری) | Auto |
| `A` | `@` | `185.199.109.153` | **DNS only** | Auto |
| `A` | `@` | `185.199.110.153` | **DNS only** | Auto |
| `A` | `@` | `185.199.111.153` | **DNS only** | Auto |
| `CNAME` | `www` | `dmj74.github.io` | **DNS only** | Auto |

نام کاربری و نام مخزن تو هر دو `dmj74` است، پس مقدار این رکورد می‌شود: **`dmj74.github.io`** (بدون `https://` و بدون اسلش آخر).

**اختیاری (IPv6):**

| Type | Name | Content |
|------|------|---------|
| `AAAA` | `@` | `2606:50c0:8000::153` |
| `AAAA` | `@` | `2606:50c0:8001::153` |
| `AAAA` | `@` | `2606:50c0:8002::153` |
| `AAAA` | `@` | `2606:50c0:8003::153` |

### نکات Cloudflare

- **حتماً Proxy را روی «DNS only» (ابر خاکستری) بگذار.** اگر پروکسی روشن باشد، گیت‌هاب نمی‌تواند گواهی SSL دامنه را صادر کند و ممکن است خطای «redirect loop» یا «Not Secure» بگیری.
- در **SSL/TLS → Overview** حالت را روی **Full (strict)** بگذار (حتی با DNS only هم ضرری ندارد).
- اگر بعد از صدور گواهی خواستی پروکسی Cloudflare را روشن کنی، باید حتماً **Full (strict)** باشد و در **Speed → Optimization** گزینه‌ی Rocket Loader خاموش باشد.

## ✅ مرحله ۴ — صدور SSL و اطمینان از بالا آمدن سایت

۱. ۵ تا ۳۰ دقیقه صبر کن (گاهی تا ۲۴ ساعت).
۲. در **GitHub → Settings → Pages** مطمئن شو پیام **«DNS check successful»** آمده باشد.
۳. تیک **Enforce HTTPS** را بزن (تا وقتی گواهی آماده نشده باشد، غیرفعال و خاکستری است).
۴. تست:

```bash
curl -I https://dmj74.ir          # باید 200 بدهد
curl -s https://dmj74.ir/data/site.json | head -c 80   # باید JSON داده‌ی سایت را بدهد
```

۴. در مرورگر `https://dmj74.ir` را باز کن — سایت dmj74 باید بالا باشد و پنل مدیریت (`🔐 مدیریت`) کار کند.

> این لحظه سایت «به‌صورت ابری» کار می‌کند: بازدیدکننده‌ها داده‌ها را از `dmj74.ir/data/site.json` می‌خوانند.

## ✅ مرحله ۵ — فعال‌سازی نوشتن (پنل مدیریت)

۱. `https://dmj74.ir` → **🔐 مدیریت** → ورود با `admin` / `admin123`
۲. یک توکن بساز: گیت‌هاب → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
   - **Repository access:** Only select repositories → مخزن `dmj74.github.io`
   - **Permissions → Repository permissions → Contents:** `Read and write`
   - **Expiration:** هرچه خواستی (مثلاً ۹۰ روز یا No expiration)
   - **Generate token** و کپی کن (یک بار بیشتر نشان داده نمی‌شود)
۳. در پنل → تب **تنظیمات** → بخش **☁️ فضای ابری مشترک (GitHub)**:
   - **کاربری گیت‌هاب:** `dmj74`
   - **نام مخزن:** `dmj74.github.io`
   - **شاخه:** `main` · **مسیر فایل داده:** `data/site.json` · **پوشه‌ی فایل‌ها:** `media/` · **مسیر sync:** `sync.json`
   - **توکن:** توکنی که ساختی
   - >>> **تست اتصال** → بعد **فعال‌سازی همگام‌سازی** ✅
۴. از این به بعد هر تغییری که «ذخیره» کنی، در مخزن کامیت می‌شود و ۳۰ ثانیه بعد روی `dmj74.ir` برای **همه** دیده می‌شود.
۵. (اختیاری) در تنظیمات، رمز `admin123` را عوض کن و **آدرس سرویس فرم پیام** را بگذار (پایین توضیح داده شده).

## ✅ مرحله ۶ — فرم پیام بازدیدکننده‌ها (اختیاری، رایگان)

در حالت GitHub، بازدیدکننده نمی‌تواند در مخزن تو بنویسد (این عمدی و برای امنیت است). برای اینکه پیام‌ها را دریافت کنی:


۳. ذخیره کن. از این پس هر پیامی که کاربر در سایت بنویسد، مستقیم به ایمیلت می‌رسد.
